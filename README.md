# DEPI - Microsoft Machine Learning Engineer Track 🚀

This repository is dedicated to documenting my progress and projects during the **Digital Egyptians Pioneers Initiative (DEPI)** - Microsoft Machine Learning Engineer track. It is organized weekly to showcase tasks, data analysis, and model development.



## 📂 Repository Structure
The projects are divided into folders by week:

* **Week 01 - Data Visualization:** * **Project:** Loan Approval Prediction.
    * **Description:** Analyzing applicant data to determine factors affecting loan eligibility.
    * **Key Techniques:** Exploratory Data Analysis (EDA), Outlier Treatment (IQR), and Pearson Correlation.

## 🛠️ Skills & Technologies
* **Languages:** Python 🐍
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn.
* **Concepts:** Data Cleaning, Statistical Visualization, Feature Engineering, and Machine Learning.

## 📈 Featured Project: Loan Approval Analysis (Week 1)
In this project, I performed a complete analysis on the `LoanApprovalPrediction.csv` dataset.
* **Visualizations:** Bar charts for categorical data, Histograms for distributions, and Scatter plots for relationships.
* **Cleaning:** Handled missing values using Median/Mode and treated outliers using the Interquartile Range (IQR).
* **Feature Selection:** Identified **Credit History** and **Education** as key predictors for loan status.
